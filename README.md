# InvokeVPN для Android

Нативный клиент Android 8.0+ для ARM64 и x86-64. Xray работает в процессе приложения и получает системный TUN от `VpnService`. [Скачать подписанный APK и контрольную сумму](https://github.com/xokeza/InvokeVPN-Android/releases/latest).

Иконки интерфейса хранятся в [отдельных SVG](app/src/main/assets/icons) и конвертируются в Android VectorDrawable при сборке. Используются иконки Lucide с уменьшенной толщиной линий и шрифт Inter с кириллицей. Таймер использует табличные цифры. Лицензии входят в APK.

## Импорт и подключение

- Вставьте `invokevpn://sub=<64-символьный ключ>`, ключ без префикса или HTTPS-ссылку в «Добавить подписку». Схема `invokevpn://` также открывается из других приложений Android. Импорт подтверждается перед запросом.
- Приложение читает JSON с `metadata` и `servers`, текстовые строки и обычную base64-подписку. [Пример JSON](examples/subscription.json) содержит демонстрационный адрес. В JSON элемент `servers` может быть ссылкой или объектом с полем `uri` и необязательным `skip: true`.
- Для подписок InvokeVPN используется существующий URL с `format=invokevpn`. PHP возвращает отдельный JSON со сроком действия, лимитом и списком доступных узлов. Обычный формат URL продолжает обслуживать другие клиенты.
- Выберите узел, нажмите круглую кнопку и подтвердите запрос Android. Поддержаны VLESS, Trojan, Shadowsocks и Hysteria 2. SIP002-плагины Shadowsocks и obfs в ссылках Hysteria 2 не поддерживаются.
- По умолчанию пинг использует TCP. В настройках доступны ICMP, HTTPS GET и HEAD через узел, метод из подписки и таймаут. Долгое нажатие на сервер открывает его меню с проверкой задержки и подключением. Кнопка «Пинг» в уведомлении измеряет задержку активного узла.
- Чтобы включать VPN из шторки, нажмите «Настройки → Подключение → Добавить плитку VPN». На Android 8–12 плитку InvokeVPN можно добавить через меню редактирования быстрых настроек. Постоянный VPN и блокировка соединений без VPN включаются в системном разделе VPN.
- Контекстные меню используют [Liquid Glass для Android](https://github.com/QWEA0/Liquid-Glass-Android) и пружинную анимацию AndroidX. Флаги [flag-icons](https://github.com/lipis/flag-icons) упакованы в APK в SVG.

При запуске приложение проверяет стабильный релиз в GitHub. Кнопка «Установить» открывает скачивание APK в браузере. Android запросит подтверждение установки.

## Параметры VPN

- При первой установке туннель использует только IPv4, MTU 1400 и автоматический DNS. Фрагментирование TLS выключено.
- «Туннель» задаёт семейство IP, MTU, DNS-over-HTTPS, распознавание доменов, фрагментацию TLS и Mux. Дополнительные SOCKS5 и HTTP слушают `127.0.0.1:10808` и `127.0.0.1:10809`. Параметры туннеля применяются при следующем подключении.
- В «Маршрутизации» можно указать домены, IP и CIDR. Правила блокировки имеют приоритет перед правилами VPN и прямого подключения. `full:example.org` совпадает с одним доменом, `domain:example.org` также охватывает поддомены. В разделе «Приложения» можно пропускать через VPN только выбранные пакеты или отправлять выбранные пакеты напрямую.
- В «Провайдерах» настраиваются интервал фонового обновления, запуск обновления при открытии, уведомления, сортировка, HWID и User-Agent. Android планирует фоновое обновление с учётом доступности сети и энергосбережения.
- «Копия настроек» переносит параметры и темы через JSON. Для переноса подписок используются их ссылки или отдельные JSON-файлы.

## Темы и настройки

Откройте «Настройки → Импорт темы» и выберите JSON. Доступны [Графит](app/src/main/assets/themes/graphite.json), [Розовая](app/src/main/assets/themes/rose.json) и [Фиолетовая](app/src/main/assets/themes/violet.json). Цвета поддерживают форматы `#RRGGBB` и `#RRGGBBAA`. Экспорт сохраняет JSON выбранной темы через системный диалог.

Трафик российских приложений из списка и российских доменов можно направить напрямую. Настройки туннеля применяются при следующем подключении. Постоянный VPN и подключение по требованию настраиваются средствами Android. DNS туннеля обслуживается внутри Xray через HTTPS.

Фоновые задания планируются Android. Время обновления зависит от доступности сети и ограничений фоновой работы устройства. Уведомление о сроке требует разрешения Android. При `subscription-always-hwid-enable` клиент отправляет случайный идентификатор установки при последующих запросах к источнику подписки.

Ключи и конфигурации хранятся локально в зашифрованном хранилище Android Keystore. Настройки, специфичные для iOS, Android-клиент пропускает.

## Сборка

Для сборки нужны Java 17/21, kotlinc 2.2+ (или компилятор из Gradle 9.2+ через `GRADLE_HOME`), Go 1.26, Android SDK Platform 36, Build Tools 36.0.0 и NDK r28c. Сборка Xray и Android идет одной командой:

```sh
export ANDROID_HOME="$HOME/Android/Sdk"
export ANDROID_NDK_HOME="/путь/к/android-ndk-r28c"
./build-apk.sh
```

Для сборки только Android-интерфейса и ресурсов с готовым `android/.build/androidcore.aar` используйте `./build-apk.sh --reuse-core`.

Скрипт подписывает APK ключом из `$INVOKEVPN_ANDROID_SIGNING_DIR` или `~/.local/share/invokevpn/android-signing/` и создаёт его при первой сборке. Сохраните `release.p12` и пароль в защищённой резервной копии. Для обновления установленной версии нужен тот же ключ. Пакет приложения — `su.xokeza.invokevpn`.

Встроенный Xray-core версии `v1.260327.0` доступен в [официальном репозитории XTLS](https://github.com/XTLS/Xray-core/tree/v26.3.27). Android-привязка и список Go-зависимостей находятся в `core/`. Уведомления о лицензиях входят в APK.
